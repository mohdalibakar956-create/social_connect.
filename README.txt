SOCIAL CONNECT — Prototype v1

Hii ni prototype ya muonekano na urambazaji wa SOCIAL CONNECT, iliyotengenezwa kwa HTML/CSS/JavaScript na inaweza kufunguliwa kwenye Android browser.

KUFUNGUA:
1. Fungua index.html kwenye browser inayoweza kufungua local HTML, au pakia mafaili yote kwenye GitHub Pages.
2. Kwa GitHub Pages: tengeneza repository public, upload mafaili yaliyomo ndani ya folder hii (si ZIP yenyewe), kisha Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. Fungua link ya GitHub Pages kwenye Chrome. Chagua menu ya Chrome > Add to Home screen / Install app.

MUHIMU:
Hii ni FRONT-END PROTOTYPE tu. Login halisi, usajili, database, kuhifadhi picha/video online, chat ya watu wawili, follows, notifications za moja kwa moja, moderation na OpenAI AI API bado hazijaunganishwa. Kwa hatua inayofuata tutaanzisha backend salama (mfano Supabase) na kuunganisha vipengele hivyo. Usitumie taarifa binafsi halisi kwenye demo hii.
